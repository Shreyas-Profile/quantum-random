How this works

Light is made of photons. When photons arrive at a camera sensor, the exact number hitting each pixel in each frame is random — not because the camera is imprecise, but because photon arrival is fundamentally quantum. This random fluctuation, called shot noise, sits in the lowest bit of every pixel value. Scientific instruments like the ID Quantique Quantis use the same physics at the single-photon level; a webcam is a cruder version of the same idea.

The raw stream is extracted in three stages. First, the least-significant bit of every pixel across many frames is concatenated into a long bit stream. Second, a Von Neumann extractor removes any sensor bias by pairing consecutive bits and only emitting when they differ. Third, SHA-256 whitening compresses the result so any residual correlation between neighbouring pixels is destroyed. The output is then run through the NIST SP 800-22 battery for certification.

Honest caveats

A consumer webcam is not a scientific-grade single-photon detector. Some of the noise in each frame is ordinary electrical noise from the silicon sensor (thermal fluctuations, amplifier noise, ADC rounding) sitting alongside the real quantum shot noise. The output cannot be claimed as 100% quantum. What can be claimed is that the output passes the industry-standard NIST randomness test battery, and the underlying source includes a real, unavoidable quantum contribution that no amount of classical modelling could predict in advance.
