Quantum · Random number generator

A quantum random number generator built from a consumer webcam.

Light is made of individual photons that arrive at any point in space at genuinely unpredictable moments. A camera sensor measures the count of photons hitting each pixel per frame, so the last binary digit of every pixel value carries that unpredictability. This page captures those digits, cleans them with a Von Neumann extractor followed by a SHA-256 whitening pass, and certifies the output with the NIST SP 800-22 randomness test suite. Every bit shown below was produced this way from a real webcam capture.

NIST SP 800-22 certification

The US National Institute of Standards and Technology publishes the official randomness test battery that commercial generators are measured against. It runs eight statistical tests against the bit sequence, each looking for a pattern a truly random source would not produce. Each test returns a p-value between 0 and 1, which measures how plausible the observed result would be if the source really were random. The industry pass threshold is 0.01: a p-value at or above this means the test found nothing non-random. All eight tests must pass.

How this works

Light arrives in indivisible packets called photons, and each photon's arrival time is fundamentally random. When a camera sensor records a frame, each pixel counts how many photons hit it during that frame. The count fluctuates slightly even if the scene is completely still, because the number of photons arriving in any short time window is quantum-random. Whether that count ends up at an even number or an odd number is unpredictable at the quantum level, so the last binary digit of every pixel value (0 if the count was even, 1 if odd) is a genuine random bit.

The raw stream is then cleaned in two stages. A Von Neumann extractor removes any bias introduced by sensor electronics, then a SHA-256 whitening pass compresses the result so that correlations between nearby pixels are destroyed. The output is submitted to the NIST SP 800-22 battery for certification before being served from this page.
